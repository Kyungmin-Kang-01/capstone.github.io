1. 프로젝트 개요

본 프로젝트는 건축시스템설계 교과목의 캡스톤(Capstone) 과제로, 학부 2–3인 팀이 파라메트릭 설계 도구를 활용하여 실제 건물의 환경·설비·에너지 성능을 종합적으로 최적화하는 설계안을 제안하는 것을 목표로 한다. 수업에서 학습한 건물 열·빛 환경 이론, 설비 시스템 원리, 에너지 시뮬레이션 방법을 통합하여 하나의 완결된 설계 결과물로 구현한다.

단순히 도구를 사용하는 실습이 아닌, 문제 정의 → 파라메트릭 모델 구축 → 시뮬레이션 연동 → 최적화 → 근거 제시의 전 과정을 팀이 직접 설계·수행함으로써 엔지니어링 사고와 설계 감각을 함께 훈련한다.

프로젝트 기본 정보
교과목건축시스템설계 (Architectural Systems Design)
과제 유형캡스톤 프로젝트 — 그룹 과제 (2–3인)
대상 건물 중앙대학교 서울캠퍼스 내 건물 혹은 개별 구역 (팀별 선정, 지도교수 승인 필요)
캠퍼스 주변부 지형 및 인접 건물을 포함한 Rhino 3D 기하 모델이 제공될 예정이며, 이를 기반으로 일조·차양·시뮬레이션 분석을 수행한다.

2. 프로젝트 목적

2-1. 파라메트릭 설계 사고 체득

건물의 외피 형태, 창호 사양, 차양 형상, 설비 시스템 등을 수치 변수(Parameter)로 정의하고, 알고리즘 기반으로 설계 공간(Design Space)을 탐색하는 방법론을 직접 경험한다. 수백–수천 가지 조합 중에서 최적해를 도출하는 과정을 통해, 직관적 설계 결정이 초래할 수 있는 에너지 낭비와 쾌적 저하를 정량적으로 인식하게 된다.

2-2. 다목적 성능의 균형 탐색

에너지 소비(EUI), 시각쾌적(DA·DGP), 열쾌적(PMV·UTCI), 경제성(ROI·SPP), 운영 탄소(kgCO₂/m²·yr) 중 팀이 선정한 2가지 이상의 목표를 동시에 최적화하는 문제를 설정한다. Pareto 프런트로 트레이드오프를 가시화하고, 팀의 설계 판단으로 최적 균형점을 선택한다.

2-3. 근거 기반 설계 보고 역량

최적화 결과를 Baseline 모델과 정량 비교하고, "왜 이 설계안인가"를 데이터·그래프·렌더링으로 설득력 있게 제시하는 보고 역량을 기른다.

3. 프로젝트 유형

두 가지 유형 중 팀의 관심 주제와 대상 건물에 따라 하나를 선택한다. 세부 최적화 대상은 팀이 자유롭게 설정하되, 지도교수와 협의하여 확정한다.

TYPE 1
기존 건물 그린리모델링
— 건물 성능 및 실내환경 질 최적화
·외피 단열 보강 (단열재 두께·종류)
·창호 교체 시나리오 (U-값·SHGC·면적비)
·자연채광 개선 및 눈부심 제어
·실내 열쾌적·공기질 개선
·운영 에너지 및 탄소 배출 저감
·ROI·투자회수기간(SPP) 경제성 분석
TYPE 2
친환경 건축설비 최적화
— 액티브 시스템 / 신재생에너지 / 건축 요소
·액티브 설비 시스템 (HVAC·열원 시스템)
·신재생에너지 (BIPV·지붕 태양광 배치)
·설비 제어 알고리즘 (스케줄·디밍·블라인드)
·외부 차양·루버 형상 최적화
·건물 매스·개구부 파라메트릭 설계
·도시열섬·외부 열쾌적 환경 개선

4. 파라메트릭 최적화 설계 워크플로우

착수부터 발표 완성까지 수행해야 할 모든 태스크를 7단계로 정리했다. 각 단계는 선행 단계의 산출물을 입력으로 받아 다음 단계로 이어지는 선형 파이프라인 구조이며, 04 최적화 결과가 기대에 미치지 못할 경우 03 시뮬레이션 단계로 되돌아가 모델을 수정한다.

01
프로젝트 정의 — 대상 건물 · 유형 · KPI · 매개변수 설정
무엇을 바꿔서 무엇을 얼마나 개선할 것인가를 명확히 정의하는 단계로, 프로젝트 전체 방향을 결정한다. 최적화 목표(KPI)와 현재 상태(Baseline), 그리고 변화시킬 설계 변수(Parameter)의 범위를 구체적으로 정해야 이후 단계가 의미 있게 진행된다. 이 단계를 소홀히 하면 나중에 좋은 결과를 얻어도 "무엇과 비교해서 좋은지"를 말할 수 없다.
대상 건물(구역) 선정프로젝트 유형 결정 (Type 1 / 2) 최적화 목표함수(KPI) 2개 이상 선정Baseline 정의 (현황 사양·운영 조건) 최적화 매개변수 및 범위 설정 (변수 3개 이상)최적화 알고리즘 선택
문헌 검토현장 답사지도교수 상담
02
파라메트릭 모델링 — Rhino · Grasshopper 구축
01단계에서 정의한 설계 변수를 실제로 작동하는 디지털 모델로 구현하는 단계다. 설계 변수를 수치로 정의하고, 그 값이 바뀌면 건물 형태·재료·시스템이 자동으로 연동되어 바뀌는 파라메트릭 파이프라인을 구축하는 것이 목표다. 이 모델이 완성되어야 알고리즘이 수천 가지 설계 조합을 자동으로 탐색하는 04단계가 가능해진다.
제공 캠퍼스 Rhino 기하 모델 로드 및 확인 대상 건물·구역 기하 모델 구성 (인접 건물·지형 포함) Grasshopper 슬라이더(Gene) 변수 정의 건물 기하·재료·창호·차양 파라메트릭 컴포넌트 연결 Ironbug HVAC 루프 구성 (Type 2 설비 팀) Pollination BIM 모델 변환 연동 (필요시) 데이터 흐름 검증 및 오류 해결
Rhino 7/8 Grasshopper Ironbug Pollination
03
시뮬레이션 연동 및 Baseline 검증
파라메트릭 모델에 시뮬레이션 엔진을 연결하고, 최적화에 앞서 현재 상태(Baseline)의 성능 수치가 현실적으로 타당한지 반드시 확인하는 단계다. 잘못된 Baseline 위에서 최적화를 진행하면 결과 자체의 신뢰성이 사라지기 때문에, 이 검증은 생략할 수 없는 필수 관문이다. Baseline이 검증되어야 이후 최적화 결과를 "얼마나 개선되었는가"의 기준으로 삼을 수 있다.
신용산 TMY3 기상 데이터 EPW 로드 Ladybug 일사량·Sun Path 기후 분석 Honeybee 에너지 모델 구성 (열 존·재료·스케줄) Honeybee-Radiance 채광 모델 구성 (DA·DGP) ClimateStudio 통합 시뮬레이션 설정 (해당 팀) Dragonfly 도시 모델 구성 (도시 스케일 팀) Baseline 단일 시뮬레이션 실행 및 결과 검증 KPI 산출값 합리성 검토 (문헌값과 비교)
Ladybug Honeybee Honeybee-Radiance ClimateStudio Dragonfly EnergyPlus Radiance
04
최적화 알고리즘 설정 및 실행
알고리즘이 수백–수천 개의 설계 조합을 자동으로 탐색하며 설계자가 직접 시도할 수 없는 규모의 설계 공간에서 최적해를 찾아내는 단계다. 단일 목표라면 가장 좋은 하나의 해를, 복수 목표라면 서로 상충하는 목표들 사이의 최적 균형 집합인 Pareto 프런트를 도출한다. 이 단계가 파라메트릭 최적화 워크플로우의 핵심이며, 알고리즘 없이 수행한 설계는 단순 시나리오 비교에 불과하다.
알고리즘 Fitness 함수 연결 (KPI → GH 출력 연동) 세대(Generation) 수·개체 수(Population) 설정 단일목적 — Galapagos 실행 및 수렴 모니터링 다목적 — Octopus / Wallacei 실행, Pareto 프런트 생성 설계 탐색 — Colibri 반복 탐색 + Design Explorer 업로드 수렴 확인 및 파라미터 조정 후 필요 시 재실행
Galapagos Octopus Wallacei Colibri + Design Explorer
05
결과 분석 — Pareto 해석 · 민감도 분석 · 최적 설계안 선택
알고리즘이 생성한 수많은 해(Solution) 중에서 팀이 데이터에 근거하여 최종 설계안을 합리적으로 선택하는 단계다. Pareto 프런트에서 목표들 간의 트레이드오프 패턴을 읽고 균형점을 결정하며, 어떤 설계 변수가 결과에 가장 큰 영향을 주었는지 민감도를 파악한다. 선택의 근거가 데이터에서 나올 때 비로소 근거 기반 설계(Evidence-Based Design)가 완성된다.
Pareto 프런트 시각화 및 트레이드오프 해석 변수 민감도 분석 (KPI에 가장 영향 큰 변수 특정) 설계 판단 기준 수립 및 최적 균형점 선택 Baseline 대비 KPI 개선량 정량화 선택된 최적 설계안으로 최종 시뮬레이션 검증 실행 경제성 분석 (ROI·SPP) — 해당 팀 탄소 저감량 산출 (운영탄소 kgCO₂/m²·yr) — 해당 팀
Design Explorer Wallacei 통계 Excel / Python
06
시각화 — 그래프 · 분포도 · 렌더링
분석 결과를 숫자 표에서 꺼내 보는 사람이 즉각 이해할 수 있는 시각 언어로 변환하는 단계다. 아무리 뛰어난 최적화 결과도 명확하게 전달되지 않으면 설득력을 갖지 못하며, 이 단계에서 만들어진 그래프·분포도·렌더링이 07단계 보고서와 발표의 핵심 콘텐츠가 된다.
KPI 비교 그래프 (Baseline vs 최적안 — 막대/방사형) Pareto 산점도 (트레이드오프 및 선택 균형점 시각화) 변수 민감도 히트맵 또는 병렬 좌표계 평면 DA·UDI·ECI 분포 색상 지도 최적 설계안 Rhino 3D 렌더링 차양·루버·파사드 형상 도면 (해당 팀) 월별·시간대별 에너지/부하 프로파일 그래프
Grasshopper (Ladybug 시각화) Rhino 렌더링 Excel / Python matplotlib
07
보고서 및 발표자료 작성
프로젝트 전 과정을 논리적 서사로 정리하고, "왜 이 설계 변수를 선택했고, 왜 이 최적안을 채택했는가"를 데이터로 설득하는 문서와 프레젠테이션을 완성하는 단계다. 결과를 나열하는 것이 아니라 문제 정의에서 결론까지 이어지는 흐름 속에서 각 선택의 근거가 명확히 제시되어야 하며, 이것이 이 프로젝트가 단순 실습이 아닌 근거 기반 설계임을 증명하는 최종 산출물이다.
중간 진행 보고 (GH 모델 시연 + Baseline 결과 공유) 최종 보고서 작성 (배경·방법론·결과·결론) 발표 슬라이드 구성 (10분 발표 기준, 시각화 중심) Grasshopper 파일 정리 및 컴포넌트 주석 추가 설계 결정 근거 명시 — 데이터 기반 논증 공모전 출품 검토 (지도교수 상담)
